- Added multilingual installation instructions and a one-click Marketplace/HACS link.
- No clock visual or behavior changes.

## Install in Home Assistant
Open Settings → Marketplace → Add from link (or add a custom Dashboard repository in older HACS), and enter:
https://github.com/Antarikfox/obsidian-6-card

Use `type: custom:obsidian-6-card` to add it to a dashboard.

The included `obsidian-6-card.js` is the complete self-contained installable module. The offline HTML edition remains available under `standalone/` in the repository.
